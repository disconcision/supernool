# Original integrated Nool world prototype

Preserved from Nool commit `e8b38bc` during the Supernool split. The accompanying 2D app code is a frozen dependency snapshot, not the actively maintained Nool lab.

Run `npm ci`, then `npm run dev -- --port 3101`; visit `http://localhost:3101/?world`.

The current Supernool game is `../../explorations/018-painted-ground/` and runs from the repository root on port 3100.
