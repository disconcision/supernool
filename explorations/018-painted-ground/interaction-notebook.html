OBSERVED ISSUE → INTERIM REPAIR

Two rules, nearly one direction.

Factoring and distribution can share a grip contact with nearly overlapping projected targets. The current picker ranks distance to each path and holds the chosen route after the first part of the pull. A legal operation can therefore lose the contest almost every time.

Measured in one live Hollow crown view: the factoring and distribution target centers were about 5½ pixels apart, with 12-pixel-wide dots. After the route-choice repair, the four-move solution completed by pointer with all eleven rules enabled and no pin. Command-Z and redo restored the expected trees. This was tested in the in-app browser; a separate Chrome automation surface was unavailable.

Implemented: click a route name in Rewrite, or press its number (1–9) before pulling. This locks the choice for that grip while leaving every rule equipped. A hint’s explicitly shown route is also respected. To change a held choice, return near the starting pose first.

Not implemented: changing the tree’s shape to separate targets. Moving only the dots would create a mismatch between the advertised destination and the actual geometry.

This controls a hypothetical two-route sketch, not gameplay settings.

Angular spacing alone has limits: n equally spaced directions get at most 360°/n. Keyboard input currently offers eight immediate directions; that is not a guarantee of eight comfortable choices. A thumbstick would permit continuous angles, but needs device testing. Dense contacts still need an explicit fallback, a smaller rule kit, or chunking.

CURRENT GESTURE · ALTERNATIVE OPEN

The zero survives; its position need not.

A × 0 → 0

Current: feed A into zero

The disappearing operand is the handle; zero is the survivor. This gesture was chosen as an absorption metaphor, not a mathematical requirement. The shared layout then relocates zero to the former product’s attachment.

Possible: draw zero through the product

This may communicate identity correspondence better: your handle survives. It needs a gesture and motion study, particularly when A is large. Neither interpretation licenses arbitrary rewriting inside A.

The spare-hand pin is not a chunk. Select a node and press F (or Shift-click in pointer mode); press F again or Release pin to let go. It freezes the selected node’s identity, incoming connection and position. Since zero changes its incoming connection here, pinning zero can forbid absorption. No pin was needed for the verified reference route.

Implemented this pass

  • Explicit route selection before a grip, using route buttons or number keys. No automatic tree rearrangement.
  • Audio starts muted on every load. Old presets cannot enable it automatically; explicit unmute still auditions the unresolved sound experiment.

Next experiments, not commitments

Geometry control has to account for all moves from one contact, not just two: nested regrouping, swap, distribution and factoring can compete. A practical layout target might start around 30–45° for a small set, but this is an untested design hypothesis, not an ergonomic result.

The larger presets have fixed target expressions, not global algebraic normal forms.
